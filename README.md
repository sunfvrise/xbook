# 慢慢走稳 · 踝关节康复指南

面向患者的独立静态网页，使用米白、鼠尾草绿与淡杏色配色。无需安装依赖，不连接模型服务。

在本仓库根目录运行：

```bash
python3 -m http.server 3100 --bind 127.0.0.1
```

打开 http://127.0.0.1:3100/ 。也可直接打开 `index.html`。

- `index.html`：仓库入口，包含阶段导航、动作卡、身体反馈、警示症状与来源。
- `styles.css`：响应式布局、键盘焦点与减少动画设置。
- `app.js`：日期确认与持久化、阶段定位、动作步骤弹窗、视频聚焦播放。
- `resources/踝关节术后康复方案.docx`：原始资料附件。
- `resources/media/`：指南配套的 10 张原始图片与 10 段原始视频，保留原文件与水印。

日期以设备本地日期为准，按日历日计算，仅用于定位资料，不判断练习许可。首次访问默认当天并保存候选日期，通过弹窗请用户确认实际手术日或计划手术日。确认后在右上角展示日期和手术已结束/待开始的天数、周数，点击可修改；修改须确认后保存，取消或无效输入不覆盖原日期。日期及确认状态分别保存在 localStorage（`ankle-rehab-start-date`、`ankle-rehab-date-confirmed`），不发送到服务器。旧版本无法区分自动日期与主动选择，因此保留旧值并要求确认一次。之后沿用确认日期，不随当天变化重置。未来日期显示倒计时，术前不自动展示术后练习。本地存储不可用时仍可计算并显示未保存提示。页面不提供额外的清除按钮。支持方向键、Home / End 切换阶段，以及 Esc 关闭弹窗。

内容适用于慢性踝关节外侧不稳定的韧带解剖修复或重建。同期软骨或踝关节炎手术，以及其他术式和普通扭伤不直接适用。医嘱和专业评估优先于时间表；页面不提供统一训练次数、阻力或时长。

主要来源：赵嘉国（北京同仁医院足踝外科中心）整理的《踝关节外侧韧带修复或重建术后基于目标的康复方案》，原文主体来自 ESSKA-AFAS，参考《踝关节外侧不稳定》（2023）。保留原文署名，原作者注明免费开放、请勿商用。页面内容为摘要和阅读导航，不执行原文中将硬物伸入石膏的操作。警示症状来源见页面 NHS、AAOS、MedlinePlus 链接。

阶段导航包含术前预康复及六个术后阶段。未来手术日期自动定位术前，展示原指南五段髋部训练视频及对应动作要点，并保留恢复计划、冷敷和助行器具准备；术前媒体单独标注适用条件，不沿用术后许可文字。术后按 14、42、56、84、112 天边界定位，并同步更新阶段说明、重点动作、主要媒体和补充示范。确认日期和重新访问时自动定位建议阅读阶段；访问身体反馈等明确锚点时保留目标。手机阶段导航可横向滑动，并将选中阶段移入视野。手动浏览其他阶段后，可点击返回建议阅读阶段。同一阶段内不编造每日不同的训练处方。页面跨午夜或次日重新激活时重新计算阶段。阶段切换暂停旧视频；日期不会自动授权进阶。

重点动作将步骤、许可、停止条件和对应原始媒体放在同一张卡中：桌面左右对照，手机上下阅读。保留聚焦查看弹窗，补充媒体按阶段放入可展开区域。12–16 周及 16 周后没有对应专项媒体，页面保留专业评估目标并说明资料缺失，可通过阶段导航复习已有动作。图片和视频按原始比例展示；图片保留大图查看，视频不提供单独打开原文件的入口。视频使用浏览器原生 controls、内联播放和全屏；至少有 55% 可见且接近视野中心时静音自动播放，离开视野、切换阶段、页面隐藏或关闭弹窗时暂停，同时只播放一个视频。手动暂停后在本次可见期间不自动重启。

页面内视频始终保持正常绘制，不再在视频进入导航区域时隐藏或修改占位高度。顶部导航随页面正常滚动，不使用吸顶定位，从布局上避免导航与第三方浏览器接管的原生视频层重叠。全屏期间由浏览器原生界面接管，并保留播放和声音状态；退出全屏后等待 400ms 视口恢复，再计算页面可见性。

依据：[WebKit 内联与自动播放规则](https://webkit.org/blog/6784/new-video-policies-for-ios/)、[Apple WebView 内联播放配置](https://developer.apple.com/documentation/webkit/wkwebviewconfiguration/allowsinlinemediaplayback)、[阿里云浏览器接管视频说明](https://www.alibabacloud.com/help/en/vod/developer-reference/faq-about-apsaravideo-player-for-web-1)。视频不含本站额外制作的字幕，动作要点与适用限制以旁边文字补充。

媒体署名：指导赵嘉国，示范张树，拍摄齐秋实（北京同仁医院足踝外科中心）。原资料缺失的视频不使用其他难度动作替代。首次练习应由康复师示教并确认姿势。
