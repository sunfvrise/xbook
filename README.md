# 慢慢走稳 · 踝关节康复指南

面向患者的独立静态网页，使用米白、鼠尾草绿与淡杏色配色。无需安装依赖，不连接模型服务。

在本仓库根目录运行：

```bash
python3 -m http.server 3100 --bind 127.0.0.1
```

打开 http://127.0.0.1:3100/ 。也可直接打开 `index.html`。

- `index.html`：仓库入口，包含阶段导航、动作卡、身体反馈、警示症状与来源。
- `styles.css`：响应式布局、键盘焦点与减少动画设置。
- `app.js`：阶段切换、可选手术日期定位、动作步骤弹窗。
- `resources/踝关节术后康复方案.docx`：原始资料附件。
- `resources/media/`：指南配套的 10 张原始图片与 10 段原始视频，保留原文件与水印。

日期以设备本地日期为准，按日历日计算，仅用于定位资料，不判断练习许可。首次访问默认当天并保存起始日期，后续修改立即保存；之后访问沿用该日期，不随当天变化重置。日期存储在当前浏览器的 localStorage（`ankle-rehab-start-date`），不发送到服务器。“清除”也会记住清除状态，下次不重新填入当天。无效或未来日期不覆盖已保存的选择；本地存储不可用时仍可使用日期计算，并显示未保存提示。首次默认日期不代表已核实患者的实际手术日，请按真实日期修改。支持键盘左右方向键切换阶段、Home / End 跳转首尾，以及 Esc 关闭弹窗。

内容适用于慢性踝关节外侧不稳定的韧带解剖修复或重建。同期软骨或踝关节炎手术，以及其他术式和普通扭伤不直接适用。医嘱和专业评估优先于时间表；页面不提供统一训练次数、阻力或时长。

主要来源：赵嘉国（北京同仁医院足踝外科中心）整理的《踝关节外侧韧带修复或重建术后基于目标的康复方案》，原文主体来自 ESSKA-AFAS，参考《踝关节外侧不稳定》（2023）。保留原文署名，原作者注明免费开放、请勿商用。页面内容为摘要和阅读导航，不执行原文中将硬物伸入石膏的操作。警示症状来源见页面 NHS、AAOS、MedlinePlus 链接。

基础示范直接显示在动作卡片下方，也嵌入对应的动作步骤弹窗。更多媒体按原文阶段放入可展开区域，并分别标注动作许可、保护要求和进阶条件。图片可打开原图；视频使用原生播放控件，不自动播放，默认不预加载视频。开始播放新视频时暂停其他视频，关闭弹窗或折叠媒体区时暂停其中的视频。视频不含本站额外制作的字幕，动作要点与适用限制以旁边文字说明补充。

媒体署名：指导赵嘉国，示范张树，拍摄齐秋实（北京同仁医院足踝外科中心）。原资料缺失的视频不使用其他难度动作替代。卡片中的 CSS 图形仅为装饰，不能作为医学动作示范。首次练习应由康复师示教并确认姿势。
